    How it works

    The tree on the left and the folder tiles in the grid show what's where — each folder tile previews a few of the images inside it. Click a folder in the tree or double-click a tile to open it. Split view puts a second folder next to the first so you can move things between them.

    Move by dragging. Drag a file (or a folder) onto a folder tile, onto a folder in the tree, onto a breadcrumb, or into the other pane's empty space. Select several first to move them together. Nothing is ever deleted or overwritten, and Undo puts the last move back.
