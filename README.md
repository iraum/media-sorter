# Media Sorter

See what's in your folders of images **and videos**, and tidy them up by
dragging things where they belong. A folder tree on the left, one or two
folder views with thumbnails in the middle, and every folder shows a preview
of what's inside it — so you can tell what's where without opening anything.

It runs as a tiny local web app, so it works on any Linux machine regardless
of whether the desktop's own file manager is showing previews. Thumbnails are
generated by the app itself and cached on disk.

## Setup

```bash
python3 -m venv venv && ./venv/bin/pip install -r requirements.txt
./start.sh
```

Open http://localhost:5070. Everything works with a plain `python3` (3.9+).
The `imageio-ffmpeg` package in `requirements.txt` bundles a static `ffmpeg`
so **video thumbnails work without installing ffmpeg on the system**. If it
fails to install, the app still runs and video tiles are rendered by the
browser instead (mp4/webm/mov play fine; exotic containers just show a badge).

Optional, for an application-menu entry on any desktop (GNOME, KDE, XFCE, ...):

```bash
./install-desktop.sh
```

That adds **Media Sorter** (starts in the background and opens your browser)
and **Stop Media Sorter** to the menu. `./start.sh --background` and
`./start.sh --stop` do the same from a terminal.

## Looking around

- The **tree** on the left is your folders. Click one to open it; the number
  next to it is how many images and videos it holds directly.
- The **grid** shows the current folder: subfolders first, each as a tile with
  a collage of the first few images inside and a count, then the files.
  Double-click a folder to go in, double-click a file to see it full-size
  (videos play inline). The **breadcrumb** at the top takes you back up; the
  pencil lets you type a path.
- **Split view** opens a second folder beside the first. Ctrl+double-click a
  folder to open it in the other pane. Now you can see two places at once.

## Tidying up

**Drag things where they should go.** Drag a file — or a whole folder — onto:

- a folder tile in the grid,
- a folder in the tree,
- a breadcrumb segment (to move it up the hierarchy), or
- the empty space of the other pane (to move it into that folder).

Click selects, Ctrl+click adds, Shift+click selects a range, Ctrl+A selects
all; drag any selected item and they all go. Need a folder that doesn't
exist? **+ New folder** creates it in the current pane.

Nothing is ever deleted or overwritten: a name clash gets a `_1`, `_2`, …
suffix, and **Undo** (or `z`) puts the last move back, as many times as you
like in a session. If you want a "deal with later" pile, make a folder for it.

Keyboard, if you prefer it: arrows move the cursor (Shift extends the
selection), Enter opens, Space toggles selection, Backspace goes up, Tab
switches panes, `n` new folder, `z` undo, `[` `]` resize tiles, `?` help.

## Safety

- The app can only see and move things inside its **allowed roots**
  (`/mnt/spielraum` and your home folder by default; set `MEDIA_ROOTS` to
  change). Symlinks are refused everywhere, and it only lists and moves media
  files and folders — other files are invisible to it.
- Moves never overwrite, a folder can't be moved into itself, and the roots
  themselves can't be moved.
- Every move (and undo) is appended to `moves.log` next to the app, so you
  can always reconstruct where something went.
- It binds to `127.0.0.1` only. Do not point `FLASK_HOST` at `0.0.0.0` —
  anyone who can reach the port can rearrange your files.

## Configuration

Environment variables, all optional:

| Variable | Default | Meaning |
| --- | --- | --- |
| `FLASK_PORT` | `5070` | Port to listen on (avoid 5060/5061 and 6000 — browsers refuse them) |
| `FLASK_HOST` | `127.0.0.1` | Bind address (keep it local) |
| `MEDIA_ROOTS` | `/mnt/spielraum:$HOME` | Colon-separated folders the app may touch |
| `MEDIA_START_DIR` | first root | Folder to open on first launch |
| `MEDIA_CACHE` | `~/.cache/media-sorter/thumbs` | Thumbnail cache (safe to delete) |
| `FFMPEG` | auto | Path to an ffmpeg binary, if you want a specific one |
| `PYTHON` | `./venv/bin/python` | Interpreter for `start.sh` |
| `SECRET_KEY` | random | Session key; set it to keep sessions across restarts |

The browser remembers your last folders, split view, sort, filter and tile
size (in that browser only). Add `?dir=/some/path` to the URL to open a
specific folder.

## Tests

```bash
./venv/bin/python tests/smoke.py
```

Builds fixture images (and a real test video when ffmpeg is available) in a
temp folder, starts the app against them on a free port, and exercises the
API: browsing and folder summaries, thumbnails and their cache, range
requests, every path guard, CSRF, mkdir, moving files and folders with
collision renaming, and undo.
